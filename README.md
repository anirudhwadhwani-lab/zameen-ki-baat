# ज़मीन की बात

Free Hindi self-help website for land owners and buyers in Madhya Pradesh: record self-check, pre-purchase checklist, ancestral land finder, glossary, and a case summary that goes to Instagram DM (@zameen.ki.baat).

The site is a single static page: `public/index.html`. It is served as a Render static site (publish directory `public`, no build step).
